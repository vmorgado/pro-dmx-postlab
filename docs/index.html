Postlab Pro DMX

Fixture profiles and a ready-to-open Pro DMX 2 project for the Postlab lighting rig: one laser, two moving heads, eight hexagons and a smoke machine. One Markdown file defines the patch, and a small Python script builds everything else from it.

Quick start

  1. Clone the repository and install into Pro DMX. You only need Python 3.

    git clone git@github.com:vmorgado/pro-dmx-postlab.git
cd pro-dmx-postlab
python3 build.py --install

    This copies the profiles to ~/Documents/Chromateq/Profiles/Postlab/ and the project to ~/Documents/Chromateq/Projects/postlab-setup.cq5.

  2. In Pro DMX 2, open postlab-setup.cq5. All 12 fixtures are already patched.

  3. Set each fixture's DMX address to match the patch below, then connect the CQSA 512 interface.

Patch

FixtureProfileDMX channels

Every channel of every fixture is listed in postlab-lights.md.

Changing the patch

Edit the Patch table in postlab-lights.md. You can change a start or end channel, rename a fixture, or add a row to add a fixture. Then rebuild:

python3 build.py             # regenerate into the repo only
python3 build.py --install   # also copy into ~/Documents/Chromateq

The build stops with an error if two fixtures share a channel, if a row's channel count doesn't match its profile, or if a channel falls outside 1–512.

Before you program scenes

The build writes a fresh project containing only the patch. Once you've built scenes in Pro DMX, change the patch inside Pro DMX instead, or save under a new name first. --install won't overwrite an installed file that differs from the build unless you add --force, and --force replaces your scenes.

Changing a profile

Profiles are defined in the PROFILES dictionary in build.py. Each channel has a name, a Pro DMX channel type and optional presets. For example, to give the moving head's Color channel named colors once you know the DMX ranges:

ch("Color", COLOR_WHEEL, [
    preset("White", 0, 9),
    preset("Red", 10, 19, 1, LPPresetColor=255),     # color is BGR: 0xBBGGRR
    preset("Green", 20, 29, 1, LPPresetColor=65280),
]),

Update the channel map in postlab-lights.md to match, then rebuild. The channel type matters because Pro DMX effects use it to decide what they control. For example, the laser's three Pan Y heads are typed as tilt, so tilt effects move all three together.

File formats

Chromateq doesn't document these formats. They were worked out from files Pro DMX 2.3.4 writes, and build.py reproduces Pro DMX's own files byte for byte.

  • .cp1 and .ls5: a 4-byte big-endian length, followed by zlib-compressed XML.
  • .cq5: plain XML. The profiles are embedded in <LPPatch>, and LPAddress counts from 0, so DMX channel 40 is stored as LPAddress="39".
